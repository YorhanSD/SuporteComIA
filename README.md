# ⚡ AI Customer Support — Analisador Inteligente de Chamados com IA

> **Projeto de Estudos & Demonstrativo Técnico**  
> Aplicação web desenvolvida para explorar conceitos de **Vibe Coding, Engenharia de Prompt e Orquestração de Agentes de IA** aplicados à automação de suporte ao cliente.

---

## 🎯 Sobre o Projeto

O **AI Customer Support** é um painel inteligente que simula o recebimento de mensagens, feedbacks ou chamados de suporte insatisfeitos e utiliza IA para automatizar o atendimento inicial:

1. **Classificação Automática:** Categorização dinâmica do problema relatado.
2. **Matriz de Urgência & Risco:** Avaliação do nível de severidade e risco de perda do cliente (*churn*).
3. **Respostas Humanizadas:** Geração imediata de uma resposta empática e resolutiva para o cliente.
4. **Recomendação Operacional:** Indicação da melhor ação para a equipe de atendimento (estorno, notificação, priorização).

---

## 🛠️ Tecnologias Utilizadas

* **Interface & UX:** React, TypeScript, Tailwind CSS, Lucide Icons.
* **Prototipagem Rápida (Vibe Coding):** Bolt.new.
* **Engenharia de Prompt:** Estruturação de dados via JSON para consumo por APIs de IA.
* **Lógica de Aplicação:** Estado reativo em React com simulação dinâmica de processamento.
